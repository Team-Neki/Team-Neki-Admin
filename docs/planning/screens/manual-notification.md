# 수동 알림 발송 화면 기획서

## 화면 구성

| 화면명 | 설명 |
| --- | --- |
| 알림 발송 | 알림 내용과 대상을 정하고 즉시 또는 예약 발송한다. |
| 발송 이력 | 발송했거나 예약된 알림을 확인한다. |

## 1. 알림 발송

### 화면 설명

운영자가 사용자에게 보낼 알림을 작성하고 발송 방식을 선택하는 화면이다.

### 화면 구성

- 알림 제목 입력 영역
- 알림 내용 입력 영역
- 발송 대상 선택 영역
- 발송 시점 선택 영역
- 발송 버튼

### 기능별 정의

#### 알림 제목과 내용 입력

- 설명: 사용자에게 전달할 알림의 제목과 본문을 작성한다.
- 사전 조건: 알림 발송 화면에 진입해 있어야 한다.
- 필요한 데이터: 알림 제목, 알림 내용
- 처리 결과: 입력한 제목과 내용이 발송할 알림 정보로 준비된다.

#### 전체 사용자 대상 선택

- 설명: 푸시 알림을 받을 수 있는 전체 사용자를 발송 대상으로 선택한다.
- 사전 조건: 전체 사용자 목록과 사용자별 푸시 수신 가능 여부를 조회할 수 있어야 한다.
- 필요한 데이터: 사용자 식별 정보, 푸시 알림 수신 가능 여부, 푸시 발송 토큰
- 처리 결과: 알림을 받을 수 있는 전체 사용자가 발송 대상으로 설정된다.

#### 마케팅 수신 동의 사용자 대상 선택

- 설명: 마케팅 알림 수신에 동의한 사용자만 발송 대상으로 선택한다.
- 사전 조건: 사용자별 마케팅 수신 동의 정보를 조회할 수 있어야 한다.
- 필요한 데이터: 사용자 식별 정보, 마케팅 수신 동의 여부, 푸시 알림 수신 가능 여부, 푸시 발송 토큰
- 처리 결과: 마케팅 수신에 동의하고 푸시를 받을 수 있는 사용자가 발송 대상으로 설정된다.

#### Android 사용자 대상 선택

- 설명: Android 기기로 알림을 받는 사용자를 발송 대상으로 선택한다.
- 사전 조건: 사용자 기기의 운영체제 정보와 푸시 수신 가능 여부를 조회할 수 있어야 한다.
- 필요한 데이터: 사용자 식별 정보, 기기 운영체제, 푸시 알림 수신 가능 여부, 푸시 발송 토큰
- 처리 결과: Android 기기에서 푸시를 받을 수 있는 사용자가 발송 대상으로 설정된다.

#### iOS 사용자 대상 선택

- 설명: iOS 기기로 알림을 받는 사용자를 발송 대상으로 선택한다.
- 사전 조건: 사용자 기기의 운영체제 정보와 푸시 수신 가능 여부를 조회할 수 있어야 한다.
- 필요한 데이터: 사용자 식별 정보, 기기 운영체제, 푸시 알림 수신 가능 여부, 푸시 발송 토큰
- 처리 결과: iOS 기기에서 푸시를 받을 수 있는 사용자가 발송 대상으로 설정된다.

#### 즉시 발송

- 설명: 작성한 알림을 선택한 대상에게 바로 발송한다.
- 사전 조건: 알림 제목, 내용, 발송 대상이 준비돼 있고 푸시 발송 기능을 사용할 수 있어야 한다.
- 필요한 데이터: 알림 제목, 알림 내용, 발송 대상 조건, 대상 사용자의 푸시 발송 토큰
- 처리 결과: 푸시 발송이 요청되고 발송 결과가 이력에 기록된다.

#### 예약 발송

- 설명: 작성한 알림을 지정한 날짜와 시간에 발송하도록 예약한다.
- 사전 조건: 알림 제목, 내용, 발송 대상이 준비돼 있고 예약 발송을 실행할 기능이 있어야 한다.
- 필요한 데이터: 알림 제목, 알림 내용, 발송 대상 조건, 예약 일시
- 처리 결과: 알림이 예약 상태로 저장되고 예약한 시점에 발송 작업이 실행된다.

### 주요 동작

1. 알림 제목과 내용을 입력한다.
2. 발송 대상을 선택한다.
3. 즉시 발송 또는 예약 발송을 선택한다.
4. 발송 버튼을 눌러 작업을 완료한다.

### 관련 화면 전환

- 관리자 메뉴의 `수동 알림`에서 진입한다.
- 발송 완료 후 발송 이력 화면에서 결과를 확인한다.

## 2. 발송 이력

### 화면 설명

발송이 완료됐거나 예약된 알림을 목록으로 확인하는 화면이다.

### 화면 구성

- 발송 상태 구분
- 알림 제목
- 발송 대상
- 발송 방식
- 발송 또는 예약 일시
- 상세 보기와 예약 취소 동작

### 기능별 정의

#### 발송 이력 조회

- 설명: 즉시 발송했거나 예약한 알림을 목록으로 확인한다.
- 사전 조건: 알림 발송 요청과 처리 결과가 이력으로 저장돼 있어야 한다.
- 필요한 데이터: 알림 식별 정보, 알림 제목, 발송 대상 조건, 발송 방식, 발송 상태, 발송 또는 예약 일시
- 처리 결과: 발송 이력이 최신 목록으로 표시된다.

#### 발송 내용 상세 확인

- 설명: 선택한 발송 이력의 알림 내용과 발송 정보를 확인한다.
- 사전 조건: 확인할 발송 이력 항목이 존재해야 한다.
- 필요한 데이터: 알림 식별 정보, 알림 제목과 내용, 발송 대상 조건, 발송 방식, 발송 상태, 관련 일시
- 처리 결과: 선택한 알림의 상세 정보가 표시된다.

#### 예약 발송 상태 확인

- 설명: 예약한 알림이 발송 대기 중인지 발송됐는지 확인한다.
- 사전 조건: 예약 발송 정보와 처리 상태가 저장돼 있어야 한다.
- 필요한 데이터: 알림 식별 정보, 예약 일시, 발송 상태
- 처리 결과: 예약 알림의 현재 상태가 목록과 상세 화면에 표시된다.

#### 예약된 발송 취소

- 설명: 아직 발송되지 않은 예약 알림을 취소한다.
- 사전 조건: 대상 알림이 예약 상태이며 아직 발송되지 않아야 한다.
- 필요한 데이터: 알림 식별 정보, 예약 일시, 발송 상태
- 처리 결과: 예약 실행이 중단되고 알림 상태가 취소로 변경된다.

### 주요 동작

1. 목록에서 알림 제목과 발송 상태를 확인한다.
2. 항목을 선택해 발송 내용을 확인한다.
3. 예약 상태인 알림은 취소할 수 있다.

### 관련 화면 전환

- 알림 발송 화면과 발송 이력 화면을 서로 이동한다.
