# 수동 알림 발송 화면 기획서

## 화면 구성

| 화면명 | 설명 |
| --- | --- |
| 알림 발송 | 알림 내용과 대상을 정하고 즉시 또는 예약 발송한다. |
| 발송 이력 | 발송했거나 예약된 알림을 확인한다. |

## 1. 알림 발송

### 화면 설명

운영자가 사용자에게 보낼 알림을 작성하고 발송 방식을 선택하는 화면이다.

### 화면 구성

- 알림 제목 입력 영역
- 알림 내용 입력 영역
- 발송 대상 선택 영역
- 발송 시점 선택 영역
- 발송 버튼

### 제공 기능

- 알림 제목과 내용 입력
- 전체 사용자 대상 선택
- 마케팅 수신 동의 사용자 대상 선택
- Android 또는 iOS 사용자 대상 선택
- 즉시 발송
- 날짜와 시간을 지정한 예약 발송

### 주요 동작

1. 알림 제목과 내용을 입력한다.
2. 발송 대상을 선택한다.
3. 즉시 발송 또는 예약 발송을 선택한다.
4. 발송 버튼을 눌러 작업을 완료한다.

### 관련 화면 전환

- 관리자 메뉴의 `수동 알림`에서 진입한다.
- 발송 완료 후 발송 이력 화면에서 결과를 확인한다.

## 2. 발송 이력

### 화면 설명

발송이 완료됐거나 예약된 알림을 목록으로 확인하는 화면이다.

### 화면 구성

- 발송 상태 구분
- 알림 제목
- 발송 대상
- 발송 방식
- 발송 또는 예약 일시
- 상세 보기와 예약 취소 동작

### 제공 기능

- 발송 이력 조회
- 발송 내용 상세 확인
- 예약 발송 상태 확인
- 예약된 발송 취소

### 주요 동작

1. 목록에서 알림 제목과 발송 상태를 확인한다.
2. 항목을 선택해 발송 내용을 확인한다.
3. 예약 상태인 알림은 취소할 수 있다.

### 관련 화면 전환

- 알림 발송 화면과 발송 이력 화면을 서로 이동한다.
