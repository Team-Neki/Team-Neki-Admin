# 네키 어드민 1차 화면 기획

네키 어드민에서 우선 제공할 운영 기능의 화면 구성을 정리한다. 이 문서 모음은 화면에 어떤 정보와 동작이 필요한지, 기능 제공을 위해 어떤 데이터와 시스템 연동이 필요한지 빠르게 공유하기 위한 화면 기획서다.

## 문서 목록

| 기능 | 화면 기획서 | 주요 화면 |
| --- | --- | --- |
| 수동 알림 발송 | [manual-notification.md](./manual-notification.md) | 알림 작성, 발송 이력 |
| 지점 관리 | [store-management.md](./store-management.md) | 지점 목록, 지점 등록·수정 |
| 사전 관리 | [dictionary-management.md](./dictionary-management.md) | 사전 유형별 목록, 항목 등록·수정 |
| 미지원 브랜드 관리 | [unsupported-brand-management.md](./unsupported-brand-management.md) | 미지원 브랜드 목록 |

## 공통 화면 구성

- 각 기능은 왼쪽 관리자 메뉴에서 진입한다.
- 목록 화면은 화면 제목, 검색·필터 영역, 주요 실행 버튼, 결과 표 순서로 구성한다.
- 등록이나 수정이 필요한 기능은 목록 화면에서 폼 화면 또는 팝업으로 이어진다.
- 작업 결과는 성공 또는 실패 안내로 확인할 수 있게 한다.

## 문서 작성 기준

- 화면에서 확인할 정보와 실행할 동작을 중심으로 작성한다.
- 기능이 동작하기 위해 필요한 데이터와 시스템 연동을 함께 기록한다.
- 상세 정책, 권한 체계, API 주소, 데이터 타입과 검증 규칙은 다루지 않는다.
- 실제 구현 과정에서 화면이 추가되거나 합쳐질 수 있다.
