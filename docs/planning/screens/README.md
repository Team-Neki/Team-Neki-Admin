## 공통 화면 구성

- 각 기능은 왼쪽 관리자 메뉴에서 진입한다.
- 목록 화면은 화면 제목, 검색·필터 영역, 주요 실행 버튼, 결과 표 순서로 구성한다.
- 등록이나 수정이 필요한 기능은 목록 화면에서 폼 화면 또는 팝업으로 이어진다.
- 작업 결과는 성공 또는 실패 안내로 확인할 수 있게 한다.

## 문서 작성 기준

- 화면에서 확인할 정보와 실행할 동작을 중심으로 작성한다.
- 각 기능 바로 아래에 기능의 사전 조건과 필요한 데이터를 함께 기록한다.
- 상세 정책, 권한 체계, API 주소, 데이터 타입과 검증 규칙은 다루지 않는다.
- 실제 구현 과정에서 화면이 추가되거나 합쳐질 수 있다.

## 기능별 작성 형식

각 화면의 기능은 다음 형식으로 작성한다.

```markdown
#### 기능명

- 설명: 기능이 하는 일
- 트리거: 기능이 시작되는 사용자 동작 또는 시스템 사건
- 사전 조건: 기능이 동작하기 전에 준비돼야 하는 상태나 정보
- 필요한 데이터: 화면 또는 서버가 기능 수행에 사용하는 정보
- 처리: 사전 조건과 데이터를 이용해 수행하는 핵심 동작
- 처리 결과: 기능 수행 후 화면이나 데이터에 나타나는 변화
```

사전 조건은 기능 구현에 필요한 전제만 기록한다. 내부 값 이름, API 필드, 세부 정책이나 입력 제한처럼 별도 협의가 필요한 내용은 포함하지 않는다.
