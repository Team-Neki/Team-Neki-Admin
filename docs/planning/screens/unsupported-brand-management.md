# 미지원 브랜드 관리 화면 기획서

## 화면 구성

| 화면명 | 설명 |
| --- | --- |
| 미지원 브랜드 목록 | 현재 지원하지 않는 브랜드를 목록으로 확인한다. |

## 1. 미지원 브랜드 목록

### 화면 설명

서비스에서 아직 지원하지 않는 브랜드 정보를 모아 확인하는 화면이다.

### 화면 구성

- 브랜드 검색 영역
- 정렬 선택 영역
- 시트 형태의 브랜드 목록

### 제공 기능

- 미지원 브랜드 목록 조회
- 브랜드명 검색
- 미지원 상태 우선 정렬
- 시트 형태로 목록 확인

### 주요 동작

1. 화면에 진입해 미지원 브랜드 목록을 확인한다.
2. 브랜드명을 입력해 특정 브랜드를 찾는다.
3. 정렬을 사용해 필요한 항목을 모아 본다.

### 관련 화면 전환

- 관리자 메뉴의 `미지원 브랜드 관리`에서 진입한다.
- 목록 안에서 검색과 정렬을 수행하며 별도 상세 화면으로 이동하지 않는다.

## 기능 요구사항

- 미지원 브랜드 목록을 조회할 수 있어야 한다.
- 브랜드명으로 원하는 항목을 검색할 수 있어야 한다.
- 미지원 상태인 항목이 우선 보이도록 정렬할 수 있어야 한다.
- 목록을 시트 형태로 확인할 수 있어야 한다.

## 필요한 데이터

- 브랜드 식별 정보
- 브랜드명
- 현재 지원 여부
- 목록에 표시할 브랜드 정보

## 시스템 연동

- 브랜드별 지원 상태를 조회하는 기능
- 미지원 브랜드 목록을 검색하고 정렬하는 기능
- 미지원 브랜드 데이터를 시트 형태로 제공하는 기능
