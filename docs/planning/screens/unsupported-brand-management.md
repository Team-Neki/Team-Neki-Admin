# 브랜드 관리 화면 기획서

## 기능 개요

국내 네컷사진 브랜드 종류를 한곳에 목록화하고, 각 브랜드의 Android·iOS QR 스캔 지원 여부와 지도 내 브랜드 정보 표시 여부를 관리하는 기능이다. 지원 여부와 관계없이 모든 브랜드를 다루므로 메뉴명은 `브랜드 관리`로 표시한다. QR 지원 여부와 지도 표시 여부에 따른 브랜드는 두 줄의 체크박스 필터를 조합해 확인한다.

- 원문: [네키 어드민 기능 목록](https://sprint.suitestudy.com:4641/wiki/cmsa129da000hkb01b6bn2siv)
- 진입 메뉴: 운영 > 브랜드 관리
- 관련 화면: 브랜드 목록, 브랜드 추가, 브랜드 정보 수정

현재 프로토타입은 목 adapter가 제공하는 식별된 브랜드 전체를 조회·추가·수정한다. 실제 API가 준비되면 같은 화면 계약을 유지한 채 서버의 전체 브랜드 목록과 추가·수정 동작을 연결한다.

## QR 파싱 로직 조회

브랜드 목록 상단의 `QR 파싱 로직` 버튼으로 플랫폼별 이미지 획득 규칙을 조회한다.

- 화면 경로: `?view=qr-parsing`
- Android 탭: QR 진입 호스트, WebView 진입 즉시 또는 다운로드 안내 후 WebView 흐름, 이미지 URL 종료 규칙, 결과 타입을 표시한다.
- iOS 탭: 네이티브 API·URL 조립·리다이렉트·HTML 링크·WebView 다운로드 전략과 이미지 확장자를 표시한다.
- 브랜드별 상세 기준은 [QR 이미지 획득·화이트리스트 기준](../qr-platform-flow.md)을 따른다.
- 화면은 조회 전용 목 데이터로 동작하며, 실제 화이트리스트 수정이나 API 연동은 범위에 포함하지 않는다.

## 기능에 필요한 정보

- 관리 대상인 네컷사진 브랜드를 식별할 수 있어야 한다.
- 브랜드별 대표 이름을 확인할 수 있어야 한다.
- 각 브랜드의 Android QR 스캔과 iOS QR 스캔 지원 여부를 각각 확인할 수 있어야 한다.
- 각 브랜드의 정보가 지도에 표시되는지 확인할 수 있어야 한다.
- 브랜드 정보가 마지막으로 변경된 시점을 확인할 수 있어야 한다.
- 실제 데이터 형식과 값 이름은 백엔드 API 스펙에 맞춰 결정한다.

## 현재 프로토타입의 QR 지원 기준

프로토타입의 QR 스캔 지원 여부는 Android와 iOS 저장소의 실제 QR 처리 구현을 각각 기준으로 맞춘다.

### Android

- 설정 근거: Android `local.properties`에 존재하고 값이 설정된 브랜드별 URL·이미지 URL 항목
- 구현 근거: `QRScanViewModel`의 지원 URL 판별과 `PhotoWebViewClient`의 브랜드별 이미지 URL 감지 분기
- 확인 기준일: 2026-08-06

현재 QR 스캔을 지원하는 브랜드는 다음 6개다.

- 인생네컷
- 포토이즘
- 포토시그니처
- 하루필름
- 포토그레이
- 모노맨션

### iOS

- 저장소: [Team-Neki/Neki-iOS](https://github.com/Team-Neki/Neki-iOS)
- 구현 근거: `DefaultQRCodeScanRepository`에 등록된 `QRCodeParsingStrategy`와 `QRCodeBrand.hostKeywords`
- 확인 기준일: 2026-08-06

현재 iOS QR 스캔을 지원하는 브랜드는 다음 7개다.

- 인생네컷
- 포토이즘
- 포토그레이
- 포토시그니처
- 하루필름
- 모노맨션
- 아우라픽

포토시그니처와 포토시그니처 CODE는 앱 내부에서 서로 다른 파싱 전략을 사용하지만 어드민에서는 하나의 `포토시그니처` 브랜드로 합쳐 표시한다. `플랜비스튜디오`는 iOS enum에 존재하지만 host와 파싱 전략이 연결되지 않아 현재는 미지원으로 표시한다.

화이트리스트 운영에 필요한 비밀이 아닌 QR 진입 호스트, 이미지 호스트·경로, 파일명 패턴과 브랜드별 파싱 방식은 [QR 이미지 획득·화이트리스트 기준](../qr-platform-flow.md)에 기록한다. 설정 파일의 앱 키, Webhook URL 등 비밀 값은 어드민 코드나 문서로 복사하지 않는다. 현재 어드민 목 데이터에는 플랫폼별 지원 판별 결과만 반영한다. 지도 표시 여부는 플랫폼별 QR 처리와 별개인 관리 항목으로 유지한다.

실제 API가 준비되면 Android 설정 파일을 어드민이 직접 읽는 구조로 연결하지 않는다. 서버가 제공하는 브랜드별 기능 상태를 adapter에서 화면 모델로 변환하며, Android 지원 범위가 바뀔 때 서버 데이터와 어드민 표시가 함께 갱신되는 운영 절차를 별도로 정한다.

## 현재 프로토타입의 지도 표시 기준

2026-08-03 운영 확인 기준으로 지도에 표시하는 브랜드는 다음 11개다.

- 포토이즘
- 인생네컷
- 포토그레이
- 포토시그니처
- 하루필름
- 플랜비 스튜디오
- 돈룩업
- 모노맨션
- 포토랩플러스
- 픽닷
- 비룸 스튜디오

위 목록에 없는 브랜드는 프로토타입에서 지도 미표시 상태로 둔다. 지도 표시 여부는 QR 스캔 지원과 독립적으로 관리하므로, 지도에 표시되지만 QR 스캔은 지원하지 않는 브랜드가 있을 수 있다.

실제 API 연결 후에는 서버의 지도 노출 정책을 기준으로 표시하며, 브랜드명이 아니라 안정적인 브랜드 식별자를 이용해 QR 지원 현황과 지도 표시 현황을 결합한다. 식별자 형식과 응답 필드명은 API 스펙이 확정될 때 결정한다.

## 1. 브랜드 목록

### 화면 설명

식별된 전체 네컷사진 브랜드와 Android QR·iOS QR·지도 표시 여부를 표 형태로 확인하고 관리하는 화면이다. 세 항목의 상태를 각각 구분해 관리하며, 어느 기능도 제공하지 않는 브랜드도 목록에서 제외하지 않는다.

### 화면 구성

- 컴팩트한 브랜드 보기 필터 영역: QR 지원·지도 표시 행의 지원/미지원 체크박스, 초기화
- 브랜드 추가
- 브랜드명 검색 영역
- 브랜드 목록 표
- 페이지 이동 영역

### 목록 표시 정보

| 항목 | 설명 |
| --- | --- |
| 브랜드명 | 식별된 네컷사진 브랜드의 대표 이름 |
| Android QR | Android 앱에서 QR 스캔 처리가 가능하면 O, 불가능하면 X |
| iOS QR | iOS 앱에서 QR 스캔 처리가 가능하면 O, 불가능하면 X |
| 지도 표시 | 지도에서 해당 브랜드 정보와 부스를 표시하면 O, 표시하지 않으면 X |
| 최근 수정일 | 브랜드 정보가 마지막으로 변경된 날짜 |
| 작업 | 브랜드 정보와 플랫폼별 QR·지도 표시 여부 수정 |

### 브랜드 보기 필터

- 큰 단일 선택 버튼 묶음 대신 두 행의 체크박스 필터를 컴팩트하게 배치한다.
- 첫 번째 `QR 지원` 행에는 `지원`, `미지원` 체크박스를 제공한다. 지원은 Android 또는 iOS 중 하나라도 QR 처리가 가능하면 지원으로 계산한다.
- 두 번째 `지도 표시` 행에는 `표시`, `미표시` 체크박스를 제공한다.
- 같은 행에서 여러 항목을 선택하면 OR 조건으로 적용하고, QR 지원 행과 지도 표시 행은 AND 조건으로 조합한다.
- 아무 항목도 선택하지 않은 행은 해당 기능의 상태를 제한하지 않고 전체로 처리한다.
- 각 체크박스에는 전체 브랜드 목록을 기준으로 계산한 해당 상태의 브랜드 수를 함께 표시할 수 있다.
- 브랜드 지원 정보를 수정하면 체크박스별 브랜드 수와 필터 결과를 즉시 다시 계산한다.
- 필터 영역의 `초기화`는 아이콘과 텍스트를 함께 표시한다. 필터가 비활성일 때도 같은 공간을 유지해 영역 높이가 바뀌지 않도록 한다.
- `초기화`를 선택하면 두 행의 체크박스 선택을 모두 해제한다.
- 필터를 변경하거나 초기화하면 목록의 첫 페이지로 이동한다.

### 전체 브랜드 목록 조회

- 화면에 진입하면 지원 여부와 관계없이 식별된 전체 네컷사진 브랜드를 표시한다.
- 브랜드명 가나다순으로 정렬해 표시한다.
- Android QR, iOS QR과 지도 표시는 서로 독립된 항목으로 표시한다.
- 두 기능을 모두 지원하는 브랜드, 일부 기능만 지원하는 브랜드, 모두 지원하지 않는 브랜드를 같은 목록에서 확인할 수 있어야 한다.
- 브랜드 수정 후 변경된 정보를 목록에 즉시 반영한다.

### 브랜드명 검색

- 운영자가 입력한 브랜드명을 기준으로 목록을 검색한다.
- 검색 결과에는 입력한 이름과 관련된 브랜드만 표시한다.
- 검색어를 변경하면 목록의 첫 페이지로 이동한다.
- 검색어를 지우면 현재 선택한 QR 지원·지도 표시 체크박스 조건에 해당하는 목록을 다시 표시한다.

### 검색과 필터 조합

- 브랜드명 검색과 선택한 QR 지원·지도 표시 체크박스 조건을 함께 적용한다.
- 검색어와 두 필터 행 조건을 모두 만족하는 브랜드만 표시한다.
- 필터 영역의 초기화는 체크박스 선택을 모두 해제하고 브랜드명 검색어는 유지한다.
- 검색 결과 없음 상태의 `검색과 필터 초기화`는 검색어와 모든 체크박스 선택을 함께 지운 뒤 목록의 첫 페이지로 이동한다.

### 목록 동작

- 각 브랜드에서 정보 수정을 선택할 수 있다.
- 지원 여부는 목록에서 바로 바꾸지 않고 수정 팝업에서 검토한 뒤 저장한다.
- 추가·수정이 완료되면 해당 브랜드의 Android QR·iOS QR·지도 표시 값을 함께 갱신한다.

### 페이지 이동

- 브랜드가 많아지면 페이지 번호 방식으로 목록을 나눠 표시한다.
- 운영자는 이전 또는 다음 페이지와 원하는 페이지 번호를 선택할 수 있다.
- 한 페이지에는 최대 30개 브랜드를 표시한다.

### 화면 상태

#### 조회 중

- 브랜드 목록을 불러오는 동안 목록 영역에 로딩 상태를 표시한다.

#### 브랜드 데이터 없음

- 서버 또는 목 adapter가 반환한 브랜드가 없으면 아직 식별된 브랜드가 없다는 안내를 표시한다.

#### 검색 결과 없음

- 검색이나 필터 조건에 해당하는 브랜드가 없다는 안내를 표시한다.
- 검색과 필터 조건을 초기화할 수 있는 동작을 제공한다.

#### 조회 실패

- 브랜드 목록 조회에 실패했다는 안내를 표시한다.
- 운영자가 목록을 다시 불러올 수 있는 동작을 제공한다.

### 브랜드 목록 기본 흐름

1. 운영자가 브랜드 관리 화면에 진입한다.
2. 지원 여부와 관계없이 전체 네컷사진 브랜드를 확인한다.
3. 필요한 경우 QR 지원·지도 표시 행의 체크박스를 조합하고 브랜드명을 검색한다.
4. 목록에서 브랜드의 플랫폼별 QR 스캔과 지도 표시 여부를 O·X로 확인한다.
5. 필요한 경우 기존 브랜드의 정보와 기능별 상태를 수정한다.

## 2. 브랜드 추가

### 화면 설명

운영자가 새 브랜드의 대표 이름과 Android QR·iOS QR·지도 표시 여부를 등록하는 팝업이다.

### 추가 가능한 정보

- 브랜드명
- Android QR 지원 여부
- iOS QR 지원 여부
- 지도 표시 여부

### 추가 동작

- 브랜드 관리 화면 우상단에 `브랜드 추가` 버튼을 제공한다.
- 새 브랜드의 세 상태는 기본값 X로 시작한다.
- 유사한 브랜드명이 있으면 저장 전에 중복 가능성을 안내한다.
- 추가가 완료되면 새 브랜드를 목록에 반영하고 성공 안내를 표시한다.
- 실제 API가 연결되기 전에는 목 adapter 메모리에만 추가한다.

## 3. 브랜드 정보 수정

### 화면 설명

기존 브랜드의 이름과 Android QR·iOS QR·지도 표시 여부를 변경하는 화면 중앙의 팝업이다.

### 수정 가능한 정보

- 브랜드명
- Android QR 지원 여부
- iOS QR 지원 여부
- 지도 표시 여부

### 기존 정보 표시

- 수정 팝업을 열면 현재 브랜드명과 기능별 지원 여부를 표시한다.
- 운영자는 변경이 필요한 항목만 수정할 수 있다.

### 수정 저장

- 지원 여부를 변경하더라도 즉시 반영하지 않고 저장을 선택한 시점에 반영한다.
- Android QR·iOS QR·지도 표시 여부는 서로 독립적으로 변경할 수 있다.
- 저장이 완료되면 팝업을 닫고 브랜드 목록을 갱신한다.
- 변경된 두 기능의 O·X 값을 목록에 함께 갱신한다.
- 수정 완료 안내를 표시한다.

### 수정 취소

- 저장하지 않고 팝업을 닫으려 할 때 변경된 내용이 있으면 저장되지 않는다는 안내를 표시한다.
- 운영자는 팝업 닫기를 계속하거나 수정 화면으로 돌아갈 수 있다.

### 수정 실패

- 수정에 실패하면 수정 팝업을 유지한다.
- 운영자가 변경한 브랜드명과 기능별 상태는 그대로 유지한다.
- 브랜드 정보 수정에 실패했다는 안내를 표시한다.

### 브랜드 정보 수정 기본 흐름

1. 운영자가 목록에서 브랜드 정보 수정을 선택한다.
2. 시스템이 현재 브랜드명과 기능별 지원 여부를 표시한다.
3. 운영자가 필요한 정보를 변경한다.
4. 운영자가 저장을 선택한다.
5. 수정 완료 후 목록을 갱신하고 변경된 Android QR·iOS QR·지도 표시 값을 표시한다.
