# 미지원 브랜드 관리 화면 기획서

## 화면 구성

| 화면명 | 설명 |
| --- | --- |
| 미지원 브랜드 목록 | 현재 지원하지 않는 브랜드를 목록으로 확인한다. |

## 1. 미지원 브랜드 목록

### 화면 설명

서비스에서 아직 지원하지 않는 브랜드 정보를 모아 확인하는 화면이다.

### 화면 구성

- 브랜드 검색 영역
- 정렬 선택 영역
- 시트 형태의 브랜드 목록

### 기능별 정의

#### 미지원 브랜드 목록 조회

- 설명: 서비스에서 아직 지원하지 않는 브랜드를 목록으로 확인한다.
- 사전 조건: 브랜드별 현재 지원 여부를 조회할 수 있어야 한다.
- 필요한 데이터: 브랜드 식별 정보, 브랜드명, 현재 지원 여부, 목록에 표시할 브랜드 정보
- 처리 결과: 미지원 브랜드가 목록에 표시된다.

#### 브랜드명 검색

- 설명: 브랜드명을 입력해 원하는 미지원 브랜드를 찾는다.
- 사전 조건: 브랜드명을 기준으로 목록을 검색할 수 있어야 한다.
- 필요한 데이터: 검색어, 브랜드명, 현재 지원 여부
- 처리 결과: 검색어에 해당하는 미지원 브랜드만 목록에 표시된다.

#### 미지원 브랜드만 보기

- 설명: 브랜드 데이터 중 미지원 상태인 항목만 모아 확인한다.
- 사전 조건: 브랜드별 지원 여부 정보가 저장돼 있어야 한다.
- 필요한 데이터: 브랜드 식별 정보, 브랜드명, 현재 지원 여부
- 처리 결과: 미지원 상태인 브랜드만 목록에 표시된다.

#### 시트 형태로 목록 확인

- 설명: 미지원 브랜드 정보를 행과 열로 구성된 시트 형태로 확인한다.
- 사전 조건: 미지원 브랜드 정보를 동일한 항목 구조로 조회할 수 있어야 한다.
- 필요한 데이터: 미지원 브랜드 목록, 시트에 표시할 브랜드 정보
- 처리 결과: 미지원 브랜드 정보가 시트 형태의 목록으로 표시된다.

### 주요 동작

1. 화면에 진입해 미지원 브랜드 목록을 확인한다.
2. 브랜드명을 입력해 특정 브랜드를 찾는다.
3. 정렬을 사용해 필요한 항목을 모아 본다.

### 관련 화면 전환

- 관리자 메뉴의 `미지원 브랜드 관리`에서 진입한다.
- 목록 안에서 검색과 정렬을 수행하며 별도 상세 화면으로 이동하지 않는다.
