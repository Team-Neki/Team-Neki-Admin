# 사전 관리 화면 기획서

## 화면 구성

| 화면명 | 설명 |
| --- | --- |
| 사전 관리 | 사전 유형을 선택해 항목을 조회하고 관리한다. |

## 1. 사전 관리

### 화면 설명

서비스에서 사용하는 주요 명칭과 검색 관련 데이터를 유형별로 확인하고 편집하는 화면이다.

### 화면 구성

- 사전 유형 탭
- 항목 검색 영역
- 신규 항목 등록 버튼
- 유형별 항목 목록
- 항목별 수정 동작

### 사전 유형

- 동의어 사전
- 자치구 목록
- 지하철역 목록
- 브랜드명 목록

### 기능별 정의

#### 사전 유형 전환

- 설명: 동의어, 자치구, 지하철역, 브랜드명 중 관리할 사전 유형을 선택한다.
- 사전 조건: 관리 가능한 사전 유형이 구분돼 있어야 한다.
- 필요한 데이터: 사전 유형 식별 정보, 사전 유형 이름
- 처리 결과: 선택한 유형의 목록과 관리 기능이 화면에 표시된다.

#### 유형별 항목 목록 조회

- 설명: 선택한 사전 유형에 등록된 항목을 목록으로 확인한다.
- 사전 조건: 사전 항목이 유형별로 저장되고 조회될 수 있어야 한다.
- 필요한 데이터: 사전 유형, 사전 항목 식별 정보, 항목 이름 또는 값, 사용 상태
- 처리 결과: 선택한 유형에 해당하는 사전 항목이 목록에 표시된다.

#### 항목 검색

- 설명: 선택한 사전 유형 안에서 원하는 항목을 검색한다.
- 사전 조건: 사전 항목의 이름이나 값을 기준으로 검색할 수 있어야 한다.
- 필요한 데이터: 사전 유형, 검색어, 사전 항목 이름 또는 값
- 처리 결과: 검색어에 해당하는 항목만 목록에 표시된다.

#### 신규 항목 등록

- 설명: 선택한 사전 유형에 새로운 항목을 추가한다.
- 사전 조건: 등록할 사전 유형이 선택돼 있고 새로운 항목을 저장할 수 있어야 한다.
- 필요한 데이터: 사전 유형, 신규 항목 이름 또는 값, 동의어인 경우 기준 단어와 동의어 정보
- 처리 결과: 신규 항목이 서버에 저장되고 선택한 유형의 목록에 추가된다.

#### 기존 항목 수정

- 설명: 등록된 사전 항목의 내용을 변경한다.
- 사전 조건: 수정할 항목의 기존 정보를 조회하고 변경 내용을 저장할 수 있어야 한다.
- 필요한 데이터: 사전 항목 식별 정보, 기존 값, 변경한 값
- 처리 결과: 변경 내용이 서버에 저장되고 목록에 반영된다.

#### 입력한 내용 저장 및 반영

- 설명: 등록하거나 수정한 사전 데이터를 서버와 서비스에 반영한다.
- 사전 조건: 사전 데이터를 저장하고 서비스에서 사용할 수 있도록 반영하는 기능이 있어야 한다.
- 필요한 데이터: 사전 유형, 저장할 사전 항목 정보
- 처리 결과: 저장한 사전 데이터가 이후 서비스 동작에 사용된다.

### 주요 동작

1. 관리할 사전 유형을 선택한다.
2. 목록을 확인하거나 검색해 원하는 항목을 찾는다.
3. 신규 항목을 등록하거나 기존 항목을 수정한다.
4. 저장하면 변경 내용이 서버에 반영된다.

### 관련 화면 전환

- 관리자 메뉴의 `사전 관리`에서 진입한다.
- 별도의 페이지 이동 없이 탭을 선택해 사전 유형을 전환한다.
- 등록·수정 작업을 마치면 선택한 유형의 목록을 다시 확인한다.
