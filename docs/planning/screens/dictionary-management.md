# 사전 관리 화면 기획서

## 화면 구성

| 화면명 | 설명 |
| --- | --- |
| 사전 관리 | 사전 유형을 선택해 항목을 조회하고 관리한다. |

## 1. 사전 관리

### 화면 설명

서비스에서 사용하는 주요 명칭과 검색 관련 데이터를 유형별로 확인하고 편집하는 화면이다.

### 화면 구성

- 사전 유형 탭
- 항목 검색 영역
- 신규 항목 등록 버튼
- 유형별 항목 목록
- 항목별 수정 동작

### 사전 유형

- 동의어 사전
- 자치구 목록
- 지하철역 목록
- 브랜드명 목록

### 제공 기능

- 사전 유형 전환
- 유형별 항목 목록 조회
- 항목 검색
- 신규 항목 등록
- 기존 항목 수정
- 입력한 내용 저장

### 주요 동작

1. 관리할 사전 유형을 선택한다.
2. 목록을 확인하거나 검색해 원하는 항목을 찾는다.
3. 신규 항목을 등록하거나 기존 항목을 수정한다.
4. 저장하면 변경 내용이 서버에 반영된다.

### 관련 화면 전환

- 관리자 메뉴의 `사전 관리`에서 진입한다.
- 별도의 페이지 이동 없이 탭을 선택해 사전 유형을 전환한다.
- 등록·수정 작업을 마치면 선택한 유형의 목록을 다시 확인한다.

## 기능 요구사항

- 동의어, 자치구, 지하철역, 브랜드명을 유형별로 구분해 조회할 수 있어야 한다.
- 선택한 유형에 맞는 항목을 검색할 수 있어야 한다.
- 유형별 항목을 새로 등록하거나 기존 항목을 수정할 수 있어야 한다.
- 저장된 내용은 서버에 바로 반영돼야 한다.
- 저장 완료 후 화면에서 변경된 목록을 다시 확인할 수 있어야 한다.

## 필요한 데이터

- 사전 유형
- 사전 항목 식별 정보
- 사전 항목 이름 또는 값
- 동의어인 경우 기준 단어와 연결되는 동의어 정보
- 항목의 사용 상태

## 시스템 연동

- 사전 유형별 목록을 조회하는 기능
- 사전 항목을 검색하는 기능
- 사전 항목을 등록하고 수정하는 기능
- 저장된 사전 데이터를 서비스에 반영하는 기능
