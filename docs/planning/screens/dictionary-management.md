## 1. 사전 관리

### 화면 설명

서비스에서 사용하는 주요 명칭과 검색 관련 데이터를 유형별로 확인하고 편집하는 화면이다.

### 화면 구성

- 사전 유형 탭
- 항목 검색 영역
- 신규 항목 등록 버튼
- 유형별 항목 목록
- 항목별 수정 동작

### 사전 유형

- 동의어 사전
- 자치구 목록
- 지하철역 목록
- 브랜드명 목록

### 제공 기능

- 사전 유형 전환
- 유형별 항목 목록 조회
- 항목 검색
- 신규 항목 등록
- 기존 항목 수정
- 입력한 내용 저장

### 주요 동작

1. 관리할 사전 유형을 선택한다.
2. 목록을 확인하거나 검색해 원하는 항목을 찾는다.
3. 신규 항목을 등록하거나 기존 항목을 수정한다.
4. 저장하면 변경 내용이 서버에 반영된다.

### 관련 화면 전환

- 관리자 메뉴의 `사전 관리`에서 진입한다.
- 별도의 페이지 이동 없이 탭을 선택해 사전 유형을 전환한다.
- 등록·수정 작업을 마치면 선택한 유형의 목록을 다시 확인한다.
