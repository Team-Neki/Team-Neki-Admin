# 지표 화면 기획서

## 기능 개요

NEKI 클라이언트가 Amplitude로 전송하는 커스텀 이벤트를 운영자가 페이지와 기능 영역별로 조회하는 읽기 전용 화면이다. 이벤트를 등록하거나 전송하는 기능은 제공하지 않는다.

- 진입 메뉴: 운영 > 지표
- 화면 경로: `?view=analytics`
- 데이터 기준: Amplitude 이벤트 명세와 Android `core/analytics` 구현
- 현재 범위: Android 코드에서 확인한 31개 이벤트를 목 데이터로 표시

실제 이벤트 분석 API가 연결되면 서버 응답을 화면 전용 모델로 변환해 주입한다. 이벤트 정의와 실제 수집 로그를 혼동하지 않도록, 현재 화면은 “어떤 이벤트를 추적하는가”만 보여준다.

## 화면 구성

- 화면 제목: 지표
- 소개 영역: Amplitude 기준, 정의된 이벤트 수, 기능 영역 수, 코드 확인 플랫폼
- 기능 영역 필터: 전체, 앱 공통, 아카이빙, 지도, 포즈, 마이페이지
- 검색: 이벤트명, 페이지·기능, 트리거, 설명
- 목록: 이벤트명, 기능 영역, 페이지·기능, 파라미터, 트리거 시점
- 상세 팝업: 설명, 플랫폼, 파라미터의 허용 값과 선택 여부, 코드 근거 파일

## 조회 동작

#### 기능 영역 필터

- 설명: 기능 영역 하나를 선택해 해당 이벤트만 표시한다.
- 트리거: 필터 선택 또는 변경
- 처리 결과: 목록과 이벤트 개수가 즉시 갱신된다.

#### 이벤트 검색

- 설명: 이벤트명, 화면, 트리거, 설명을 기준으로 부분 검색한다.
- 트리거: 검색어 입력 또는 삭제
- 처리 결과: 조건에 맞는 이벤트만 표시한다.

#### 이벤트 상세 보기

- 설명: 목록의 이벤트명을 눌러 이벤트 정의를 확인한다.
- 트리거: 이벤트명 선택
- 처리 결과: 상세 팝업에서 파라미터와 코드 근거를 확인한다.

## 화면 상태

- 조회 중: 운영 데이터 로딩 패널
- 데이터 없음: 이벤트가 등록되지 않았다는 빈 상태
- 검색 결과 없음: 조건에 맞는 이벤트가 없다는 안내
- 조회 실패: 다시 불러오기 동작을 포함한 오류 상태

## API 연동 경계

- 현재 목 adapter는 `analyticsEvents` 배열을 반환한다.
- 실제 API 연결 시 이벤트명, 영역, 화면, 트리거, 설명, 파라미터를 화면 모델로 변환한다.
- 지표 화면의 `새로고침`은 서버 API route를 통해 Amplitude 이벤트 목록과 최근 7일 활성 사용자 데이터를 조회한다.
- Amplitude API Key와 Secret Key는 브라우저에 전달하지 않고 서버 실행 환경의 `AMPLITUDE_API_KEY`, `AMPLITUDE_SECRET_KEY`에서 읽는다.
- 키가 없거나 Amplitude 조회가 실패하면 목록을 유지한 채 수집 오류 상태를 표시한다.
- 내부 enum 이름이나 분석 저장소의 원본 필드명은 화면 계약으로 고정하지 않는다.
- 이벤트 로그 수치, 기간별 차트, CSV 다운로드는 별도 분석 기능으로 범위에서 제외한다.
