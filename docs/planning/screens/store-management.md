# 지점 관리 화면 기획서

## 화면 구성

| 화면명 | 설명 |
| --- | --- |
| 지점 목록 | 등록된 지점을 조회하고 검색한다. |
| 지점 등록·수정 | 새로운 지점을 등록하거나 기존 정보를 수정한다. |

## 1. 지점 목록

### 화면 설명

서비스에 등록된 지점을 한곳에서 확인하고 관리 작업을 시작하는 화면이다.

### 화면 구성

- 브랜드 선택 영역
- 지점명 검색 영역
- 신규 지점 등록 버튼
- 지점 목록 표
- 지점별 수정 및 폐점 처리 동작

### 기능별 정의

#### 전체 지점 목록 조회

- 설명: 서비스에 등록된 전체 지점을 목록으로 확인한다.
- 사전 조건: 등록된 지점 정보를 조회할 수 있어야 한다.
- 필요한 데이터: 지점 식별 정보, 지점명, 소속 브랜드, 지점 상세 정보, 운영 상태
- 처리 결과: 전체 지점이 목록에 표시된다.

#### 브랜드별 지점 목록 조회

- 설명: 선택한 브랜드에 속한 지점만 목록으로 확인한다.
- 사전 조건: 브랜드 목록과 지점별 소속 브랜드 정보를 조회할 수 있어야 한다.
- 필요한 데이터: 브랜드 식별 정보, 브랜드명, 지점별 브랜드 식별 정보
- 처리 결과: 선택한 브랜드에 속한 지점만 목록에 표시된다.

#### 지점명 검색

- 설명: 입력한 지점명과 일치하거나 관련된 지점을 찾는다.
- 사전 조건: 지점명을 기준으로 지점 목록을 검색할 수 있어야 한다.
- 필요한 데이터: 검색어, 지점명
- 처리 결과: 검색어에 해당하는 지점만 목록에 표시된다.

#### 지점 정보 확인

- 설명: 목록에서 선택한 지점의 정보를 확인한다.
- 사전 조건: 지점별 상세 정보를 조회할 수 있어야 한다.
- 필요한 데이터: 지점 식별 정보, 지점명, 소속 브랜드, 지점 상세 정보, 운영 상태
- 처리 결과: 선택한 지점의 정보가 표시된다.

#### 지점 수정 화면 진입

- 설명: 선택한 지점의 정보를 수정할 수 있는 화면을 연다.
- 사전 조건: 수정할 지점의 식별 정보와 기존 정보를 조회할 수 있어야 한다.
- 필요한 데이터: 지점 식별 정보, 기존 지점 정보
- 처리 결과: 기존 정보가 입력된 지점 수정 화면이 표시된다.

#### 폐점 처리

- 설명: 운영 중인 지점을 폐점 상태로 변경한다.
- 사전 조건: 대상 지점의 현재 운영 상태를 조회하고 변경할 수 있어야 한다.
- 필요한 데이터: 지점 식별 정보, 현재 운영 상태
- 처리 결과: 지점 상태가 폐점으로 변경되고 목록에 반영된다.

### 주요 동작

1. 전체 지점을 확인하거나 브랜드를 선택해 목록을 좁힌다.
2. 지점명을 입력해 원하는 지점을 검색한다.
3. 목록에서 지점을 선택해 정보를 수정하거나 폐점 처리한다.
4. 신규 지점 등록 버튼으로 등록 화면에 진입한다.

### 관련 화면 전환

- 관리자 메뉴의 `지점 관리`에서 진입한다.
- 지점 등록·수정 화면을 완료하면 지점 목록으로 돌아온다.

## 2. 지점 등록·수정

### 화면 설명

지점 정보를 입력해 새 지점을 등록하거나 기존 지점 정보를 변경하는 화면이다.

### 화면 구성

- 브랜드 선택 영역
- 지점 기본 정보 입력 영역
- 저장 버튼
- 취소 버튼

### 기능별 정의

#### 신규 지점 등록

- 설명: 새로운 지점의 정보를 입력해 서비스에 등록한다.
- 사전 조건: 선택 가능한 브랜드 목록과 지점 정보 저장 기능이 준비돼 있어야 한다.
- 필요한 데이터: 브랜드 식별 정보, 지점명, 지점 상세 정보
- 처리 결과: 신규 지점이 저장되고 지점 목록에 추가된다.

#### 기존 지점 정보 수정

- 설명: 등록된 지점의 정보를 변경해 저장한다.
- 사전 조건: 수정할 지점의 기존 정보를 조회하고 변경 내용을 저장할 수 있어야 한다.
- 필요한 데이터: 지점 식별 정보, 기존 지점 정보, 변경한 지점 정보
- 처리 결과: 변경 내용이 저장되고 지점 목록과 상세 정보에 반영된다.

### 주요 동작

1. 브랜드와 지점 정보를 입력하거나 수정한다.
2. 저장 버튼을 눌러 변경 내용을 반영한다.
3. 취소하면 변경하지 않고 지점 목록으로 돌아간다.

### 관련 화면 전환

- 지점 목록의 신규 등록 또는 수정 동작으로 진입한다.
- 저장 또는 취소 후 지점 목록으로 이동한다.
