# 부스 관리 화면 기획서

## 기능 개요

서비스에 등록된 부스를 조회하고 신규 부스를 등록하거나 기존 부스의 정보와 운영 상태를 관리하는 기능이다.

- 원문: [네키 어드민 기능 목록](https://sprint.suitestudy.com:4641/wiki/cmsa129da000hkb01b6bn2siv)
- 진입 메뉴: 운영 > 부스 관리
- 관련 화면: 부스 목록, 부스 등록, 부스 상세, 부스 수정

## 기능에 필요한 정보

- 등록된 부스 정보를 조회할 수 있어야 한다.
- 부스가 속한 브랜드를 확인할 수 있어야 한다.
- 부스 선택에 사용할 브랜드 목록을 확인할 수 있어야 한다.
- 운영 중인 부스와 폐점된 부스를 구분할 수 있어야 한다.
- 주소를 검색하고 선택한 주소의 위치 정보를 확인할 수 있어야 한다.
- 같은 브랜드에 등록된 유사한 부스명과 주소를 확인할 수 있어야 한다.
- 실제 데이터 형식과 값 이름은 백엔드 API 스펙에 맞춰 결정한다.

## 1. 부스 목록

### 화면 설명

서비스에 등록된 부스를 표 형태로 확인하고 검색, 필터와 관리 작업을 수행하는 화면이다.

### 화면 구성

- 부스명 검색 영역
- 브랜드 선택 영역
- 운영 상태 선택 영역
- 시·도 선택 영역
- 시·군·구 선택 영역
- 신규 부스 등록 버튼
- 폐점하기 버튼
- 부스 목록 표
- 페이지 이동 영역

### 목록 표시 정보

| 항목 | 설명 |
| --- | --- |
| 부스명 | 등록된 부스의 이름 |
| 브랜드 | 부스가 속한 브랜드 |
| 운영 상태 | 현재 운영 중인지 폐점됐는지 나타내는 상태 |
| 주소 | 등록된 부스의 주소 |
| 시·도 | 1단계 광역 행정구역 |
| 시·군·구 | 선택한 시·도에 속한 2단계 행정구역 |
| 최근 수정일 | 부스 정보가 마지막으로 변경된 날짜 |
| 작업 | 상세 보기, 수정 |

### 전체 부스 목록 조회

- 서비스에 등록된 전체 부스를 표 형태로 표시한다.
- 부스명 가나다순으로 정렬해 표시한다.
- 신규 부스 등록, 부스 수정 또는 폐점 처리 후 변경된 정보를 목록에서 확인할 수 있어야 한다.

### 부스명 검색

- 운영자가 입력한 부스명을 기준으로 목록을 검색한다.
- 검색 결과에는 입력한 이름과 관련된 부스만 표시한다.
- 검색어를 지우면 전체 부스 목록을 다시 표시한다.

### 브랜드 필터

- 선택 가능한 브랜드 목록을 제공한다.
- 브랜드를 선택하면 해당 브랜드에 속한 부스만 표시한다.
- 브랜드 선택을 해제하면 모든 브랜드의 부스를 다시 표시한다.

### 운영 상태 필터

- 전체, 운영 중, 폐점 상태를 구분해 볼 수 있는 필터를 제공한다.
- 상태를 선택하면 해당 상태의 부스만 목록에 표시한다.

### 지역 필터

- 지역은 `시·도`와 `시·군·구` 2단계로 필터링한다.
- 시·도를 선택하면 해당 시·도에 속한 시·군·구만 두 번째 선택지에 표시한다.
- 시·군·구를 선택하지 않으면 선택한 시·도의 모든 부스를 표시한다.
- 현재 목 데이터는 서울특별시 부스만 제공한다. 이후 다른 지역이 추가되면 동일한 계층으로 확장한다.
- 명칭과 계층은 [도로명주소 안내지도](https://m1.juso.go.kr/gismap-new/MapIndex.do)의 시도·시군구 구분과 [행정안전부 표준 행정구역 데이터](https://www.data.go.kr/data/15123406/fileData.do?recommendDataYn=Y)를 따른다.

### 검색과 필터 조합

- 부스명 검색, 브랜드·운영 상태·시·도·시·군·구 필터를 함께 적용할 수 있다.
- 적용 중인 검색과 필터 조건을 초기화할 수 있어야 한다.

### 목록 동작

- 각 부스에서 상세 보기를 선택할 수 있다.
- 각 부스에서 수정 화면으로 이동할 수 있다.
- 각 행에는 폐점 처리 버튼을 두지 않는다.
- 화면의 `폐점하기`를 선택하면 폐점 선택 모드로 전환한다.
- 폐점 선택 모드에서 운영 중인 부스의 선택 체크박스를 표시한다.
- 폐점된 부스는 선택할 수 없다.
- 하나 이상의 부스를 선택해야 폐점 확인 동작을 실행할 수 있다.
- 선택 취소로 현재 선택을 모두 해제하고, 모드 종료로 선택을 해제한 뒤 일반 목록으로 돌아갈 수 있다.

### 페이지 이동

- 부스가 많아지면 페이지 번호 방식으로 목록을 나눠 표시한다.
- 운영자는 이전 또는 다음 페이지와 원하는 페이지 번호를 선택할 수 있다.
- 한 페이지에는 최대 30개 부스를 표시한다.

### 화면 상태

#### 조회 중

- 부스 목록을 불러오는 동안 목록 영역에 로딩 상태를 표시한다.

#### 부스 없음

- 등록된 부스가 없으면 아직 등록된 부스가 없다는 안내를 표시한다.
- 신규 부스 등록 화면으로 이동할 수 있는 동작을 함께 제공한다.

#### 검색 결과 없음

- 검색이나 필터 조건에 해당하는 부스가 없다는 안내를 표시한다.
- 검색과 필터 조건을 초기화할 수 있는 동작을 제공한다.

#### 조회 실패

- 부스 목록 조회에 실패했다는 안내를 표시한다.
- 운영자가 목록을 다시 불러올 수 있는 동작을 제공한다.

### 부스 목록 기본 흐름

1. 운영자가 부스 관리 화면에 진입한다.
2. 전체 부스를 부스명 가나다순으로 확인한다.
3. 필요한 경우 부스명을 검색하거나 브랜드와 운영 상태 필터를 적용한다.
4. 목록에서 부스 상세를 확인하거나 수정한다.
5. 신규 부스 등록 버튼으로 등록 화면에 진입한다.
6. 폐점이 필요한 경우 `폐점하기`로 선택 모드에 진입해 대상 부스를 선택하고 일괄 폐점한다.

## 2. 신규 부스 등록

### 화면 설명

새로운 부스의 기본 정보와 위치를 입력해 서비스에 등록하는 별도 화면이다.

### 입력 정보

| 항목 | 설명 |
| --- | --- |
| 브랜드 | 기존 브랜드 목록에서 부스가 속한 브랜드를 선택한다. |
| 부스명 | 서비스에 표시할 부스 이름을 입력한다. |
| 주소 | 주소 검색 결과에서 부스 주소를 선택한다. |
| 위치 정보 | 선택한 주소를 기준으로 부스 위치를 확인한다. |
| 연락처 | 부스 연락처가 있는 경우 입력한다. |
| 운영 상태 | 신규 부스는 운영 중 상태로 등록한다. |

### 브랜드 선택

- 사전 관리에 등록된 기존 브랜드 목록에서 하나를 선택한다.
- 부스 등록 화면에서 새로운 브랜드를 직접 만들거나 브랜드명을 자유롭게 입력하지 않는다.

### 주소 입력

- 운영자가 주소를 직접 완성해 입력하는 대신 주소 검색을 제공한다.
- 검색 결과에서 주소를 선택하면 선택한 주소와 위치 정보를 등록 정보에 반영한다.
- 지도에서 위치를 직접 선택하는 기능은 1차 등록 화면에 포함하지 않는다.

### 중복 부스 확인

- 입력한 브랜드, 부스명과 주소를 기준으로 기존 부스와 유사한 항목이 있는지 확인한다.
- 유사한 부스가 있으면 등록을 막지 않고 운영자에게 중복 가능성을 안내한다.
- 운영자는 안내를 확인한 뒤 등록을 계속하거나 입력 정보를 수정할 수 있다.

### 등록 전 확인

운영자가 등록을 선택하면 바로 저장하지 않고 확인 팝업을 표시한다.

팝업에는 다음 내용을 표시한다.

- 브랜드
- 부스명
- 주소
- 위치 정보
- 연락처
- 최초 운영 상태

팝업에는 다음 버튼을 제공한다.

- 취소
- 부스 등록

### 등록 완료

- 등록이 완료되면 부스 목록으로 이동한다.
- 방금 등록한 부스를 목록에서 쉽게 확인할 수 있도록 강조한다.
- 등록 완료 안내를 표시한다.

### 등록 실패

- 등록에 실패하면 등록 화면을 유지한다.
- 운영자가 입력한 브랜드, 부스명, 주소, 위치와 연락처는 그대로 유지한다.
- 부스 등록에 실패했다는 안내를 표시한다.

### 신규 부스 등록 기본 흐름

1. 운영자가 부스 목록에서 신규 부스 등록을 선택한다.
2. 기존 브랜드 목록에서 브랜드를 선택한다.
3. 부스명을 입력한다.
4. 주소를 검색하고 검색 결과에서 부스 주소를 선택한다.
5. 필요한 경우 연락처를 입력한다.
6. 시스템이 기존 부스와의 중복 가능성을 확인한다.
7. 운영자가 등록을 선택하고 확인 팝업에서 입력 정보를 검토한다.
8. 운영자가 `부스 등록`을 선택한다.
9. 등록 완료 후 부스 목록으로 이동하고 신규 부스를 강조한다.

## 3. 부스 상세

### 화면 설명

부스 목록에서 선택한 부스의 전체 정보를 화면 중앙의 상세 팝업으로 확인한다.

### 상세 표시 정보

- 브랜드
- 부스명
- 주소
- 위치 정보
- 연락처
- 운영 상태
- 최근 수정일

### 상세 팝업 동작

- 팝업을 닫고 부스 목록으로 돌아갈 수 있다.
- 부스 수정 화면으로 이동할 수 있다.
- 폐점 처리는 상세 팝업에서 제공하지 않으며 부스 목록의 폐점 선택 모드에서 수행한다.

### 상세 조회 실패

- 부스 상세 정보를 불러오지 못하면 실패 안내를 표시한다.
- 운영자가 상세 정보를 다시 불러올 수 있는 동작을 제공한다.

## 4. 부스 정보 수정

### 화면 설명

기존 부스 정보를 불러와 필요한 내용을 변경하는 별도 화면이다. 신규 부스 등록과 동일한 입력 구성을 사용한다.

### 수정 가능한 정보

- 브랜드
- 부스명
- 주소와 위치 정보
- 연락처

운영 상태의 폐점 전환은 부스 정보 수정이 아니라 별도의 폐점 처리 기능에서 수행한다.

### 기존 정보 표시

- 수정 화면에 진입하면 현재 등록된 부스 정보를 각 입력 영역에 표시한다.
- 운영자는 변경이 필요한 항목만 수정할 수 있다.

### 수정 저장

- 운영자가 저장을 선택하면 변경된 부스 정보를 반영한다.
- 저장이 완료되면 부스 목록으로 이동한다.
- 수정한 부스를 목록에서 쉽게 확인할 수 있도록 강조한다.
- 저장 완료 안내를 표시한다.

### 저장하지 않고 나가기

- 입력 내용을 변경한 뒤 화면을 벗어나려 하면 변경 내용이 저장되지 않는다는 확인 안내를 표시한다.
- 운영자는 화면 이동을 계속하거나 수정 화면으로 돌아갈 수 있다.

### 수정 실패

- 수정에 실패하면 수정 화면을 유지한다.
- 운영자가 변경한 입력 내용은 그대로 유지한다.
- 부스 수정에 실패했다는 안내를 표시한다.

### 부스 수정 기본 흐름

1. 운영자가 부스 목록 또는 부스 상세에서 수정을 선택한다.
2. 시스템이 기존 부스 정보를 입력 영역에 표시한다.
3. 운영자가 필요한 내용을 변경한다.
4. 운영자가 저장을 선택한다.
5. 저장 완료 후 부스 목록으로 이동하고 수정한 부스를 강조한다.

## 5. 폐점 처리

### 기능 설명

운영 중인 부스를 하나 이상 선택해 삭제하지 않고 폐점 상태로 일괄 변경하는 기능이다. 폐점된 부스는 목록과 상세에서 계속 확인할 수 있다.

### 진입 위치

- 부스 목록 상단에 별도의 `폐점하기` 버튼을 제공한다.
- `폐점하기`를 선택하면 목록이 폐점 선택 모드로 전환된다.
- 각 행이나 부스 상세 팝업에는 폐점 처리 버튼을 제공하지 않는다.

### 폐점 대상 선택

- 폐점 선택 모드에서는 운영 중인 부스에 선택 체크박스를 표시한다.
- 이미 폐점된 부스는 선택할 수 없다.
- 하나 이상의 부스를 선택하면 선택한 부스 수를 표시하고 폐점 확인 동작을 활성화한다.
- 선택 취소를 선택하면 폐점 선택 모드는 유지한 채 현재 선택만 모두 해제한다.
- 모드 종료를 선택하면 현재 선택을 해제하고 일반 부스 목록으로 돌아간다.
- 폐점 처리 중에는 대상 선택 변경, 선택 취소와 모드 종료를 제한해 중복 요청을 방지한다.

### 폐점 확인 팝업

운영자가 하나 이상의 부스를 선택하고 폐점 확인을 선택하면 바로 상태를 변경하지 않고 확인 팝업을 표시한다.

팝업에는 다음 내용을 표시한다.

- 선택한 부스 수
- 선택한 부스의 브랜드와 부스명
- 선택한 부스가 모두 운영 중 상태인지 확인할 수 있는 정보

팝업에는 다음 버튼을 제공한다.

- 취소
- 선택한 부스 폐점

별도의 폐점 사유는 입력받지 않는다.

### 폐점 완료

- 선택한 부스를 삭제하지 않고 운영 상태를 모두 폐점으로 변경한다.
- 부스 목록을 즉시 갱신해 변경된 부스의 폐점 상태를 표시한다.
- 폐점 선택 모드를 종료하고 선택 상태를 초기화한다.
- 처리한 부스 수를 포함한 폐점 완료 안내를 표시한다.
- 폐점된 부스는 운영 상태 필터를 통해 다시 확인할 수 있다.

### 폐점 실패

- 폐점 처리에 실패하면 선택한 부스의 기존 운영 상태를 유지한다.
- 폐점 선택 모드와 선택 상태를 유지해 운영자가 다시 시도하거나 대상을 변경할 수 있게 한다.
- 선택한 부스의 폐점 처리에 실패했다는 안내와 다시 시도할 수 있는 동작을 표시한다.
- 부스 목록과 상세에는 변경 전 상태를 그대로 표시한다.

### 폐점 처리 기본 흐름

1. 운영자가 부스 목록 상단의 `폐점하기`를 선택한다.
2. 시스템이 폐점 선택 모드로 전환하고 운영 중인 부스에 선택 체크박스를 표시한다.
3. 운영자가 하나 이상의 부스를 선택한다.
4. 운영자가 폐점 확인을 선택한다.
5. 시스템이 선택한 부스 수와 대상 목록을 포함한 확인 팝업을 표시한다.
6. 운영자가 팝업에서 `선택한 부스 폐점`을 선택한다.
7. 선택한 부스의 상태를 폐점으로 변경한다.
8. 부스 목록을 갱신하고 선택 모드를 종료한 뒤 폐점 완료 안내를 표시한다.
