# 지점 관리 화면 기획서

## 화면 구성

| 화면명 | 설명 |
| --- | --- |
| 지점 목록 | 등록된 지점을 조회하고 검색한다. |
| 지점 등록·수정 | 새로운 지점을 등록하거나 기존 정보를 수정한다. |

## 1. 지점 목록

### 화면 설명

서비스에 등록된 지점을 한곳에서 확인하고 관리 작업을 시작하는 화면이다.

### 화면 구성

- 브랜드 선택 영역
- 지점명 검색 영역
- 신규 지점 등록 버튼
- 지점 목록 표
- 지점별 수정 및 폐점 처리 동작

### 제공 기능

- 전체 지점 목록 조회
- 브랜드별 지점 목록 조회
- 지점명 검색
- 지점 정보 확인
- 지점 수정 화면 진입
- 폐점 처리

### 주요 동작

1. 전체 지점을 확인하거나 브랜드를 선택해 목록을 좁힌다.
2. 지점명을 입력해 원하는 지점을 검색한다.
3. 목록에서 지점을 선택해 정보를 수정하거나 폐점 처리한다.
4. 신규 지점 등록 버튼으로 등록 화면에 진입한다.

### 관련 화면 전환

- 관리자 메뉴의 `지점 관리`에서 진입한다.
- 지점 등록·수정 화면을 완료하면 지점 목록으로 돌아온다.

## 2. 지점 등록·수정

### 화면 설명

지점 정보를 입력해 새 지점을 등록하거나 기존 지점 정보를 변경하는 화면이다.

### 화면 구성

- 브랜드 선택 영역
- 지점 기본 정보 입력 영역
- 저장 버튼
- 취소 버튼

### 제공 기능

- 신규 지점 정보 입력 및 등록
- 기존 지점 정보 확인 및 수정

### 주요 동작

1. 브랜드와 지점 정보를 입력하거나 수정한다.
2. 저장 버튼을 눌러 변경 내용을 반영한다.
3. 취소하면 변경하지 않고 지점 목록으로 돌아간다.

### 관련 화면 전환

- 지점 목록의 신규 등록 또는 수정 동작으로 진입한다.
- 저장 또는 취소 후 지점 목록으로 이동한다.

## 기능 요구사항

- 전체 지점과 특정 브랜드의 지점을 구분해 조회할 수 있어야 한다.
- 지점명으로 원하는 지점을 검색할 수 있어야 한다.
- 신규 지점 정보를 등록하고 기존 지점 정보를 수정할 수 있어야 한다.
- 폐점 처리된 지점은 운영 중인 지점과 상태가 구분돼야 한다.
- 등록, 수정, 폐점 처리 결과가 목록에 반영돼야 한다.

## 필요한 데이터

### 브랜드 데이터

- 브랜드 식별 정보
- 브랜드명

### 지점 데이터

- 지점 식별 정보
- 지점명
- 소속 브랜드
- 지점 상세 정보
- 운영 또는 폐점 상태

## 시스템 연동

- 브랜드 목록을 조회하는 기능
- 전체 또는 브랜드별 지점 목록을 조회하는 기능
- 지점명 검색 기능
- 지점 등록과 수정 기능
- 지점 상태를 폐점으로 변경하는 기능
